# Qais's Adventure 🎮

A retro pixel-art dodge game built for Qais's 42nd birthday! Survive 42 seconds dodging falling birthday surprises — cakes, presents, balloons, and stars — to win.

**Play now:** https://devnull37.github.io/qais-adventure/

## Controls

- **Mobile:** Tap the left/right buttons at the bottom of the screen
- **Desktop:** Arrow keys or A/D keys to move

## Game Rules

- Dodge the falling birthday obstacles
- Survive **42 seconds** to win (one for each year!)
- Each obstacle dodged adds to your score
- High score is saved locally

## Tech

- Pure HTML5 + CSS3 + vanilla JavaScript (single file, no build step)
- Works offline after first load
- Mobile-first responsive design
- Retro pixel aesthetic with "Press Start 2P" font
- Confetti celebration animation on win

## Deployment

Deployed via GitHub Pages from the `main` branch.
